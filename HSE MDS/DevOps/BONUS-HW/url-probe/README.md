# url-probe

Проверяет, отвечают ли URL из списка, и выводит результат в формате метрик Prometheus. Написан на Python, внешних зависимостей нет (только стандартная библиотека).

```bash
python3 probe.py urls.txt
```

| Что | Как |
|-----|-----|
| Список URL | файл, один URL на строку; пустые строки и строки с `#` пропускаются |
| `PROBE_TIMEOUT` | таймаут одной проверки в секундах, по умолчанию `5` |
| `PROBE_OUTPUT_DIR` | если задан, метрики записываются в `<каталог>/url_probe.prom` (атомарно, через временный файл), иначе печатаются в stdout |
| Лог | по строке на URL в stderr: `OK 200 0.760s https://example.com` |
| Код возврата | `0` — все URL живы, `1` — хотя бы один не отвечает, `2` — ошибка запуска |

Метрики:

| Метрика | Что означает |
| ------- | ------------ |
| `probe_success{url}` | `1`, если получен ответ с кодом 2xx/3xx, иначе `0` |
| `probe_http_status_code{url}` | код ответа, `0` — ответа нет |
| `probe_duration_seconds{url}` | сколько заняла проверка |
| `probe_last_run_timestamp_seconds` | время последнего запуска (unix time) |

Скрипт проверяет список один раз и завершается. Повторять проверки он сам не умеет.
